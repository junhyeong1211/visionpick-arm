> 모든 각도는 **µs/도 = 11.1 (추정값)** 으로 환산한 값이다. 관절별 실측 전이므로 각도는 참고용이고, 코드는 펄스(µs) 기준으로 동작한다.

## 하드웨어

| 항목 | 내용 |
|---|---|
| 제어 | Arduino UNO + PCA9685 (I2C 0x40, 50Hz) |
| 서보 전원 | 6V 10A 어댑터 → 퓨즈 10A → 스위치 → PCA 단자대 (무부하 6.15V) |

## J5 그리퍼 (SG90, CH4)

| 항목 | 값 (µs) | 날짜 | 비고 |
|---|---|---|---|
| 최대 열림 (GRIP_OPEN) | 1100 | 11/25 | 부딪히기 직전 |
| 완전 닫힘 (패드 없음) | 1400 | 11/25 | 1500에서 링크가 꺾여 걸린 적 있음 |
| 큐브 CONTACT (패드 부착 후) | ≈ 1310 | 11/26 | 30mm 큐브, 손가락 안쪽에 고무 패드 |
| **GRIP_HOLD (현재)** | **1340** | 11/26 | 30초 유지 후 정상 열림. CONTACT + 30 |
| 코드 상한 (MAXP) | 1360 | 11/26 | GRIP_HOLD + 20 |

**그리퍼 주의 (11/26 실험)**
- CONTACT보다 깊게 누르면(예: 1420) SG90이 스톨 상태에서 명령을 받지 않음. 전원을 껐다 켜거나 **PCA 신호를 끊었다 다시 주면** 풀림.
- 유지 중 전압 6.15V로 강하 없음 → 전원 문제 아님. SG90 자체 한계 또는 손상(1500 걸림 이력) 추정.
- 근본 해결: MG90S(금속 기어)로 교체 예정. 교체 후 CONTACT·GRIP_HOLD 재측정 필요.
- SG90 데드밴드 약 10µs → 10µs 이하 조정은 움직이지 않음. 20µs 단위로 조정.

## 이동 규칙

| 항목 | 값 | 이유 |
|---|---|---|
| ORDER_DOWN | J1 → J4 → J3 → J2 | 내려갈 때 어깨를 마지막에: 물체·책상을 쓸지 않게 |
| ORDER_UP | J2 → J3 → J4 → J1 | 올라갈 때 어깨를 먼저: 들어 올린 뒤 회전 |
| 스텝 | 5µs / 10ms | 약 45°/s (추정). 11/25 버전은 3µs / 15ms (약 18°/s) |
| J4 보정 | J2나 J3를 1° 더 숙이면 J4 +11µs | 그리퍼 각도 유지 (경험 규칙) |
